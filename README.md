# Accessibility updates

- Added skip links and semantic landmarks so keyboard users can move to the main content more quickly.
- Added descriptive link labels and page-specific navigation states to improve clarity and orientation for screen reader users.
- Increased color contrast on text and controls to meet WCAG AA standards for readability.
- Added visible focus styles on links, buttons, and form fields to support keyboard navigation.
- Added form labels, a fieldset/legend, and inline validation messaging to make the contact form accessible.
- Replaced low-contrast placeholder elements with clearer text and accessible structure across all pages.

# Visual design

- I used proximity to group related content such as the project cards and studio metrics so users can understand content relationships at a glance.
- I used similarity to keep repeated card styles, typography, and spacing consistent across the site so sections feel like one cohesive system.
- The color palette is consistent across all pages: warm ivory backgrounds, deep navy headings, teal accents, and dark orange calls to action.

# WAVE and accessibility checklist

- I checked the site structure for heading order, landmark usage, and keyboard access to reduce common WAVE errors.
- I verified that every form control has a matching label and that the contact form uses a legible fieldset and legend.
- I confirmed all interactive elements have clear focus states and readable contrast against their backgrounds.
- I reviewed each page for empty elements, missing alternative text, and redundant or unclear navigation labels.
